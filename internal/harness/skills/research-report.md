---
description: Research a question on the web and write a sourced report the user can read and share.
---
1. Restate the question and what a good answer contains in todo.md. When the question is vague, pick the most useful reading and say which one you picked.
2. Search broadly first with web_search, using two to four different phrasings, then read the best sources in full with web_fetch. Prefer primary sources: official sites, papers, filings and documentation.
3. Save notes to notes.md as you go, each with the source URL, so nothing is lost when the context fills up.
4. Check every important claim against a second independent source. Where sources disagree, say so and give both.
5. Write report.md:
   - The answer in two or three sentences at the top.
   - The findings, each with its source linked inline.
   - What is uncertain or could not be found.
   - A list of sources.
6. Note the date of time-sensitive facts such as prices, versions and news. Never invent a source or a quote.
7. End with idle, giving the answer in short and the path to report.md.
